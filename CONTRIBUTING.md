# Contributing to Commit Café

This is a practice repository. Small changes make the best first pull requests.

1. Clone the repository, or fork it first if you do not have push access.
2. Start from an up-to-date `main` and create a branch:
   `git switch -c your-name/add-a-snack`.
3. Make one focused change, such as adding a menu item or improving a sentence.
4. Open each HTML page in your browser and check its navigation.
5. Use `git diff` to review your work, then stage the specific files and commit.
6. Push your branch and open a pull request against `main`.
7. Ask a partner to review it and respond to their feedback.

Use clear commit messages that explain what changed. Keep practice rebases on
branches you own. Coordinate with your partner before rewriting a shared branch.

## Ideas for a first change

- Add a seasonal drink to `menu.html`.
- Change the café's opening hours in `index.html`.
- Improve spacing or colors in `styles.css`.
- Add another detail to the story in `about.html`.
